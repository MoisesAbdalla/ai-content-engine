# Abdalla Tech — AI content engine

Code-driven marketing for my PC repair business: **Instagram carousels, promo pieces and website
imagery generated by Python scripts**, with AI image generation where it adds value — so a weekly
posting calendar can be produced in minutes and stays 100% on-brand.

![carousel slide](reparo-componente/slide_01.png)

## What's inside

| Piece | What it does |
|---|---|
| `carousel_engine.py` | Reusable carousel renderer (1080×1350, 4:5) with the brand identity: gradient, circuit patterns, logo, cover → tips → CTA. Takes a declarative `spec` dict and renders every slide with Pillow + NumPy. |
| `build_all.py` | The content plan as data: each carousel (positioning, educational, myth-busting, comparison) is a spec — title, tips, footer — rendered in one run. |
| `CALENDARIO.md` | The weekly posting calendar with the rationale for the order of themes. |
| `*/legenda.txt` | The caption for each post, next to its slides. |
| `build_promo.py`, `build_neu.py`, `build_cyber.py` | Three art directions for the same ad (GPU repair), generated procedurally for A/B comparison. |
| `design-philosophy.md` | The "Diagnostic Neon" art direction the generators follow. |
| `gen_site_images.py` | Website imagery generated with **Gemini image generation** (`gemini-3.1-flash-image`) via the REST API, with a `--test` mode for a single cheap image. |
| `build_site.py` | Free, local PIL fallback for site assets (hero, section bands, avatar tiles). |
| `impressora/` | Logo generation, background removal and two carousel variants for the printer-care post. |

## Running

```bash
pip install pillow numpy
# fonts: point FONTS_DIR to a folder with the .ttf files used by the scripts (default: ./fonts)
python build_all.py            # renders every carousel into its folder
GEMINI_API_KEY=... python gen_site_images.py --test
```

## Why code instead of a design tool

Every post is a small data structure, so new content is a few lines in `build_all.py`, the brand
stays consistent by construction, and an AI agent can draft new carousels end to end — copy,
layout and caption — for me to review.

**Stack:** Python · Pillow · NumPy · Gemini image API · Claude Code
